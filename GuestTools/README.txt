Isola — буфер обмена и раскладка (0.8.0)

В гостевой macOS запусти Install Clipboard.command двойным щелчком.
Для обновления запусти его повторно с диска Isola Tools новой версии.
Помощник устанавливается для текущего пользователя, без sudo и доступа к сети.
Текст, PNG и TIFF: до 10 МиБ на обмен. Обычные файлы: до 64 МиБ суммарно,
до 128 файлов за раз, в обе стороны. Папки, ссылки и обещанные файлы не передаются.
Файлы сохраняются во временную папку получателя, затем доступны для вставки в Finder.
Слишком большой или недоступный набор оставляет буфер получателя без изменений.
После первого подключения буфер хоста имеет приоритет.

Раскладка синхронизируется в обе стороны. В окне VM Cmd+Space переключает её сразу для обеих ОС.
Точно такой же источник должен быть установлен в госте; доступный встроенный источник
помощник включает автоматически. Перевод интерфейса macOS не меняется.
Буфер и синхронизация раскладки включаются независимо, после перезапуска VM.
Помощник запускается автоматически при входе в учётную запись гостя.

Зеркалирование Desktop и Downloads удалено. При обновлении помощник восстанавливает
сохранённые локальные папки гостя из ~/Library/Application Support/Isola Integration/.
Файлы хоста не перемещаются и не удаляются. Посторонние папки и ссылки не заменяются.
Добавляй папки явно в Isola → Интеграция → Общие папки: они доступны в
/Volumes/My Shared Files, без перезапуска VM и без участия помощника.
Для больших файлов используй прямой доступ в общей папке.

«Не усыплять гостевую macOS» запускает caffeinate -dis внутри гостя.
Если процесс завершается, Tools запускает его снова. Галочка хоста независима.
Настройки заставки, блокировки и пароля не меняются. Сон хоста приостанавливает VM.
После обновления приложения переустанови Tools один раз: гостевая копия не
обновляется автоматически. При изменении галочек повторная установка не нужна.
После паузы гость запрашивает актуальную раскладку хоста.
Бинарный канал буфера не использует Base64; файлы обрабатываются в фоне.

Удаление помощника: Uninstall Clipboard.command на диске Isola Tools.

Optimize performance в настройках Isola уменьшает движение, прозрачность/размытие
и анимации окон/Dock. Переключается без перезапуска VM после обновления помощника.
Выключение возвращает прежние настройки. Dock перезапускается; некоторые приложения
нужно открыть заново, либо выйти и войти в гостевую учётную запись.

Для сетевого подключения в Isola 0.8 обнови Tools один раз в госте.
Новая версия передаёт форму курсора отдельно от видео и скрывает второй курсор
на время удалённого управления. При отключении курсор возвращается автоматически.
