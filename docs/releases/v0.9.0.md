# Isola 0.9.0

Save your VM, restart Isola and pick up where you left off. This release also adds
LAN access from another Mac and improves networking, clipboard sharing and guest integration.

## What's new since 0.5.0

- **Suspend and resume:** save memory and device state to disk, release host resources,
  then resume after restarting Isola. **Save & Quit** does both steps from the quit dialog.
  Disk and configuration checks prevent replaying an incompatible saved state.
- **VMs on your local network:** discover shared VMs from another Mac running Isola.
  Connect without a password by default, or enable password protection.
- **Native video streaming:** hardware HEVC/H.264, Retina-aware sizing, adaptive bitrate,
  bounded frame queues and separate video, input and clipboard connections.
  Guest cursor shapes and hotspots are sent separately for local rendering.
- **Faster clipboard transfers:** binary transport and background file I/O for text,
  images and regular files. Keyboard layout and clipboard relay also work with remote VMs.
- **Shared-folder improvements:** add, remove and change access while the VM runs,
  with stable mount names. Desktop/Downloads mirroring has been removed;
  updated Tools includes migration back to local guest folders.
- **Time through SOCKS:** answer guest NTP requests from the host clock, without
  requiring UDP support from the proxy or bypassing it for internet access.
- **Independent sleep controls:** keep guest macOS awake with `caffeinate -dis`,
  and optionally prevent host idle sleep with a separate switch.

## Download and update

1. Download **Isola-0.9.0-macos-arm64.zip**, unzip it and move **Isola.app** to Applications.
2. Requires **Apple Silicon and macOS 14 or later**.
3. When updating from an older release, shut down guest macOS and quit the old
   Isola first. Existing VM files stay in their current folder.
4. Inside the guest, run **Isola Tools → Install Clipboard.command** once to update
   older Tools. Checkbox changes do not require rerunning the installer.
5. Update both Macs to this version when using LAN sharing.

The app is **ad-hoc signed, not Developer ID signed or notarized**. If macOS blocks
its first launch, follow Apple's [Open Anyway instructions](https://support.apple.com/en-us/102445).
The attached **SHA256SUMS.txt** verifies the ZIP. Source code is available under
**MIT**; third-party notices are included in the app.

## Suspend and sharing notes

- Allow free host disk space equal to guest RAM plus **2 GB** for suspension.
- Resume on the **same Mac**. Some host macOS updates can invalidate Apple's state
  format; shut down the guest before upgrading host macOS or moving the VM.
- Saved memory is **not a disk backup**. Discarding a saved state loses open apps
  and unsaved work, while keeping files already written to the VM disk.
- Network sessions and remote viewers need to reconnect after resuming.
- When sharing is enabled without a password, other computers on the local network
  can connect and control the VM. Enable password protection when needed.
- LAN sharing currently supports Mac clients and one controller at a time. Remote
  audio is not included. SOCKS supports IPv4 TCP/DNS and local NTP, not general UDP/QUIC.
- Clipboard limits remain 10 MiB for text/images and 64 MiB / 128 regular files.
  Use shared folders for directories or larger transfers.

## Validation

Automated networking, clipboard, keyboard, sleep, cursor, video, discovery,
saved-state and resource tests passed. Save/failure recovery/restore were exercised
in separate processes using a firmware-only VM with NAT and SOCKS adapters.
The release ZIP is checked after extraction, including its code signature and checksum.

Full macOS guest Tools reconnection after resume is not yet confirmed by an end-to-end
test. Streaming tests use loopback; they do not replace testing between two physical Macs.
