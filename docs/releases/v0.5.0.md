# Isola 0.5.0

The first public release of Isola: a lightweight native Swift app for a fast,
comfortable macOS virtual machine on Apple Silicon.

## Features

- A minimal SwiftUI interface with machine tabs, a collapsible settings panel,
  light/dark appearance and a new transparent retro Mac icon.
- macOS installation from an Apple restore image, adjustable CPU/RAM and sparse disks.
- Disk growth with a backup, Recovery relocation and automatic expansion of the main APFS volume.
- Direct networking or SOCKS5, with IP, CIDR and domain bypass rules.
- Clipboard sharing for text, images and files, plus bidirectional keyboard layout sync.
- Shared Desktop and Downloads, and additional folders with a read-only option.
- A guest performance switch to reduce visual effects and restore previous settings.
- Recovery startup and per-machine settings.

## Download and install

1. Download **Isola-0.5.0-macos-arm64.zip**, unzip it and move **Isola.app** to Applications.
2. Requires **Apple Silicon and macOS 14 or later**. Intel Macs are not supported.
3. This build is **ad-hoc signed, not Developer ID signed or notarized**. If macOS
   blocks the first launch, follow Apple's [Open Anyway instructions](https://support.apple.com/en-us/102445)
   in System Settings → Privacy & Security.
4. Choose resources, select a network mode and install macOS from an IPSW.
5. Inside the guest, run **Isola Tools → Install Clipboard.command** once to enable
   clipboard, keyboard, folder integration and performance settings.

For an existing VM, shut down the guest and quit the old app before replacing it.
VM data stays in its existing folder. Re-run the guest installer if using older Tools.

`SHA256SUMS.txt` contains the archive checksum. Source code is available below and
under the **MIT License** in the repository. Third-party notices are included in the app.

## Current limitations

- One running guest at a time. SOCKS mode supports IPv4 TCP and DNS, not general UDP/QUIC.
- Domain bypass rules rely on guest DNS; encrypted DNS and shared CDN addresses affect matching.
- Clipboard: text/images up to 10 MiB; regular files up to 64 MiB and 128 files. No folders or symlinks.
- Shared Desktop/Downloads are bidirectional: edits and deletions affect both systems.
- Disk expansion requires an APFS host volume and a supported guest disk layout.
- Some guest visual effects require reopening apps or logging out and back in.

Build/signature verification and automated networking, clipboard, settings,
folder-permission and performance-restoration checks have been run locally.
Guest installation and integration have also been exercised during development;
this is an early release, not a guarantee for every macOS version or proxy provider.
