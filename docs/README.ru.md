<h1 align="center">Isola</h1>
<p align="center"><strong>Лёгкое приложение на Swift для быстрого и удобного запуска виртуальной macOS.</strong></p>
<p align="center">Нативный интерфейс. Минимум лишнего. Ещё один Mac — в одном окне.</p>
<p align="center"><a href="https://github.com/itrcz/isola/releases/latest">Скачать</a> · <a href="../README.md">English</a> · <a href="../LICENSE">MIT</a></p>

![Isola в тёмной теме: машина и ресурсы](screenshots/machine-dark.png)

Isola написана на **Swift и SwiftUI** и использует **Apple Virtualization framework**.
Для SOCKS-сети есть небольшой помощник на Go. Интерфейс полностью нативный, без
Electron и веб-оболочки.

## Возможности

| Функция | Что умеет |
| --- | --- |
| **Минималистичный интерфейс** | Вкладки машин, запуск в один клик, скрываемая панель настроек, светлая и тёмная темы. **⌘,** открывает настройки. |
| **Интернет напрямую или через прокси** | NAT хоста или SOCKS5. Исключения по IP, подсети и домену, например `*company.com`. |
| **Общий буфер обмена** | Текст, изображения и обычные файлы в обе стороны. |
| **Синхронизация языка** | Раскладка синхронизируется между системами. **⌘Space** в госте переключает обе. |
| **Общие папки** | Подключение, отключение и выбор режима чтения без перезапуска VM. Доступ через virtiofs, постоянные имена папок. |
| **VM по сети** | Подключение к VM с другого Mac через Isola, без пароля по умолчанию или с защитой паролем. |
| **Без сна** | Отдельные галочки для гостевой macOS и для хоста во время работы VM. |
| **Время через прокси** | Локальный NTP отвечает временем хоста, без поддержки UDP у прокси и без прямых запросов в интернет. |
| **Оптимизация эффектов** | Меньше движения, прозрачности, размытия и анимаций. Отключение возвращает прежние настройки гостя. |
| **Настраиваемые ресурсы** | CPU, RAM и увеличение диска вместе с основным томом macOS. Перед расширением сохраняется резервная копия. |
| **Запуск в Recovery** | Встроен в меню запуска виртуальной машины. |

## Первый запуск

Нужен **Mac на Apple Silicon и macOS 14 или новее**. Intel и другие гостевые ОС
пока не поддерживаются. Для скачивания и установки macOS требуется от 45 ГБ
свободного места; фактический расход зависит от версии системы и файлов.

1. Скачай **ZIP для macOS arm64** из [Releases](https://github.com/itrcz/isola/releases/latest).
2. Распакуй и перенеси **Isola.app** в «Программы».
3. Выбери CPU, память, размер диска и режим сети: напрямую или через прокси.
4. Укажи `.ipsw` для Apple Silicon или скачай образ с серверов Apple прямо в Isola.
5. Установи macOS, запусти машину и пройди первоначальную настройку.
6. В гостевой macOS открой диск **Isola Tools** и запусти **Install Clipboard.command**.
   Это включает помощник для буфера, раскладки, управления сном и настройки эффектов.

Сборка подписана **ad-hoc**, без Developer ID и нотариализации Apple. Если macOS
блокирует первый запуск, воспользуйся кнопкой **«Всё равно открыть»** в настройках
«Конфиденциальность и безопасность» по [инструкции Apple](https://support.apple.com/ru-ru/102445).
В релизе есть `SHA256SUMS.txt` для проверки скачанного архива.

Для обновления штатно выключи гостевую macOS и закрой старую Isola, затем замени
приложение. Данные VM остаются в прежней папке. При обновлении гостевого помощника
повторно запусти его установщик с диска Isola Tools.

## Как это работает

**Сеть.** Прямой режим использует NAT Apple. SOCKS5 передаёт IPv4 TCP и DNS, без
прямого выхода при сбое прокси. Укажи числовой IP сервера; логин и пароль необязательны.
Пароль хранится в Связке ключей macOS. Правила обхода — по одному в строке:

```text
*company.com
10.0.0.0/8
203.0.113.5
```

Правило домена включает поддомены, но не `evilcompany.com`. Оно опирается на DNS
гостя: DoH/DoT обходят сопоставление, а общие IP CDN могут затронуть другие сайты.
В SOCKS-режиме нет общего UDP/QUIC и IPv6. Изменения сети применяются после перезапуска VM.

**Время.** В режиме SOCKS обычные IPv4 NTP-запросы по UDP 123 получают время
хоста локально. Прокси не обязан поддерживать UDP. На хосте и в госте должна быть
включена автоматическая установка даты и времени. Локальный сервер доступен и по
адресу `10.77.0.1`: команда `sntp 10.77.0.1` в госте проверит ответ, не меняя часы.
В прямом режиме работает обычная сетевая синхронизация времени.

**Папки.** Добавляй нужные папки в «Настройки → Интеграция → Общие папки».
Они появятся в **Finder → My Shared Files** в госте; Isola Tools для этого не нужен.
Добавление, отключение и изменение режима чтения применяются без перезапуска VM.
Большие файлы удобнее открывать прямо здесь, без передачи через буфер.
В режиме записи изменения и удаления затрагивают файлы хоста.

Зеркалирование Desktop и Downloads удалено в 0.6. Обновлённый Isola Tools вернёт
сохранённые локальные папки гостя из `~/Library/Application Support/Isola Integration/`.
Файлы хоста остаются на хосте; посторонние локальные папки и ссылки не заменяются.
При необходимости Desktop и Downloads можно добавить как обычные общие папки.

**Буфер и язык.** Текст и изображения — до 10 МиБ. Файлы — до 64 МиБ суммарно
и 128 файлов; папки, ссылки и file promises не передаются. Для синхронизации
раскладки тот же источник ввода должен быть доступен в госте. Файловые операции
и кодирование выполняются в фоне. В Tools 0.6 передача идёт в бинарном формате,
без Base64 и ожидания таймера между порциями данных. Для обновления повторно
запусти **Install Clipboard.command** с нового диска Isola Tools.

**Сон.** «Не усыплять гостевую macOS» запускает `caffeinate -dis` в госте.
Tools 0.7 перезапускает его при неожиданном завершении, а хост повторно применяет
настройку при переподключении помощника. Настройки заставки, пароля и блокировки
не меняются. Независимая галочка хоста запускает `caffeinate -is`; его экран может
гаснуть. Обе по умолчанию выключены и применяются сразу. Сон хоста приостанавливает VM.

Галочка показывает желаемое состояние; текст под ней — подтверждение из гостя.
Если написано **«Обнови Isola Tools»**, один раз запусти **Install Clipboard.command**
с актуального диска Tools. Помощник установлен отдельной копией внутри гостя:
обновление приложения на хосте не заменяет её. При каждом переключении галочки
повторный запуск установщика не нужен. После сна гость сначала получает раскладку хоста.

**VM по локальной сети.**

1. Запусти VM на хосте. Открой **Настройки → Интеграция → Доступ по сети**
   и включи **Разрешить подключение к VM**. При запросе macOS разреши запись
   экрана и локальную сеть; для записи экрана может понадобиться перезапуск Isola.
2. На другом Mac с Isola 0.8 нажми **+ → В локальной сети**, выбери VM и нажми
   **Подключиться**. Оба Mac должны находиться в одной локальной сети.
3. По умолчанию пароль не нужен: к расшаренной VM может подключиться любой
   из этой сети. Для защиты включи **Защитить паролем** и сохрани пароль на хосте.
   При подключении клиент спросит пароль и сможет запомнить его в Связке ключей.

VM продолжает работать на хосте. Одновременно подключается один управляющий
клиент; **Забрать управление** возвращает VM владельцу. Отключение доступа,
остановка VM или смена пароля закрывают соединение. При следующем запуске VM
доступ нужно включить заново. Для постоянной доступности включи запрет сна хоста.

Передаётся только окно VM через ScreenCaptureKit. Аппаратные кодирование и
декодирование VideoToolbox поддерживают до **60 кадров/с**. Разрешение гостя
подстраивается под окно клиента и Retina: до 4096 пикселей по стороне и 8,85 Мп.
В меню с иконкой дисплея доступны три режима:

- **Retina** — чёткий текст, HEVC с запасным H.264, целевой битрейт 12–80 Мбит/с в зависимости от разрешения.
- **Сбалансированный** — меньше пикселей и расхода сети с сохранением пропорций окна.
- **Быстрый отклик** — аппаратный H.264 с низкой задержкой и обычной плотностью пикселей.

Управление, видео и буфер идут по отдельным зашифрованным соединениям. Декодер
подтверждает кадры; одновременно в пути не больше двух. При перегрузке сохраняется
только последний исходный кадр, а битрейт снижается. Внизу показаны кодек,
разрешение, FPS, скорость передачи и RTT сети. RTT — **не полная задержка экрана**;
на неподвижном рабочем столе FPS закономерно падает.

Обнови **оба Mac до 0.8** — протокол изменился. Для локальной отрисовки формы
курсора и правильной точки клика один раз установи **Isola Tools 0.8 в госте**.
Во время удалённого управления Tools скрывает гостевой курсор и передаёт его
форму отдельно; при отключении или истечении времени связи возвращает курсор.
Со старыми Tools клиент показывает стрелку, а гость может рисовать второй указатель.
Через Tools также работают текст, изображения и файлы в буфере и синхронизация
раскладки. Буфер и раскладка владельца на хосте изолированы от удалённой сессии.

Общие папки принадлежат хосту. Передачи звука, папок клиента, пробуждения хоста
по сети и одновременной локальной/удалённой VM пока нет. Скорость зависит от
локальной сети, разрешения и нагрузки на хост.

Соединение использует TLS 1.2 ECDHE-PSK/ChaCha20-Poly1305. В защищённом режиме
ключ получается из пароля через PBKDF2-SHA256; пароль хранится в Связке ключей.
В открытом режиме ключ публичный, проверки личности подключающегося нет.
Обнаружение через Bonjour и проверка подсети ограничивают доступ локальной сетью.
Режим интернета VM — напрямую или через прокси — от этого подключения не зависит.

**Диск.** Папка VM по умолчанию: `~/Library/Application Support/Isola/VM`.
Образ занимает место по мере записи. Увеличение требует APFS на хосте и поддерживаемой
разметки гостя. Isola сохраняет копию **Before expansion …**, переносит Recovery
и расширяет основной том. Отключать SIP или удалять Recovery не нужно. Для отката
выключи VM и добавь папку резервной копии как существующую машину.

**Эффекты.** Оптимизация меняет визуальные настройки гостя, а не выделение CPU/GPU.
Некоторым приложениям нужен перезапуск или повторный вход в гостевую учётную запись.
Одновременно работает одна VM. Язык интерфейса Isola берётся из настроек хоста:
русский или английский.

## Сборка из исходников

Нужны Apple Silicon, Xcode command line tools с SDK macOS 14+, [Go 1.27.1+](https://go.dev/dl/)
и Python 3 для тестов.

```sh
git clone https://github.com/itrcz/isola.git
cd isola
bash scripts/build.sh
open dist/Isola-0.9.0.app
```

Скрипт собирает приложение, сетевой и гостевой помощники, образ Isola Tools, иконку,
лицензионные уведомления и подпись. Xcode-проект и сторонние Swift-пакеты не нужны.

```sh
bash scripts/test.sh
bash scripts/test.sh --ui
bash scripts/test.sh --disk
bash scripts/test.sh --stream
bash scripts/release.sh
```

Тест диска требует APFS и Python 3.11+. Тесты используют временные данные. Упаковка
создаёт свежий ZIP и SHA-256 в `dist/release/` и проверяет подпись после распаковки.
Подробнее — в [CONTRIBUTING.md](../CONTRIBUTING.md).

## Пауза с сохранением состояния

Нажми **⏸ Приостановить** на панели: Isola сохранит память и устройства VM в её
папку и освободит CPU и RAM. Приложение можно закрыть. После открытия нажми
**Продолжить macOS** — гостевые приложения останутся открытыми. Через
**⌘Q → Сохранить и выйти** это можно сделать за один шаг. Закрытие окна само по
себе оставляет VM работающей.

Для сохранения нужно свободное место на хосте: объём RAM гостя плюс 2 ГБ.
Изменение ресурсов, диска и интеграции заблокировано, пока состояние сохранено.
Чтобы поменять настройки, продолжи VM и выключи macOS. **Удалить сохранённое
состояние** позволяет загрузиться заново, но открытые приложения и несохранённая
работа будут потеряны; диск VM сохраняется. Это не резервная копия диска.

Восстановление работает **на том же Mac**. Перед обновлением macOS хоста или
переносом VM на другой Mac выключай гостя: формат Apple может стать несовместимым.
Isola проверяет диск и конфигурацию перед восстановлением и не запускает VM
заново молча при ошибке. Сетевые соединения и удалённые клиенты переподключаются.
Установленный Isola Tools автоматически перезапускает канал интеграции.
